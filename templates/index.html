PDF Crawler

By Praveen Kumar

Enter a landing page URL. The tool will crawl child pages under that section, download PDFs, and return a ZIP containing the PDFs and an Excel audit log. The excel file will contain a second sheet containing an audit of all child pages under the url.

This web app uses Render's free to use plan. Consequently, I have placed some usage limitations so the app can run smoothly:

  • Only nsw.gov.au urls are allowed.
  • The app is set to timeout at 10 minutes, so don't go crawling entire departments, ex: all of NESA. If your crawl fails, narrow your scope to child pages.
  • Maximum downloadable pdfs are limited to 1000. If your pages are very pdf heavy, again, narrow your scope to child pages and work up from there.
  • Maximum pages crawled is set to 500. So if your department contains a larger number of web pages, please narrow down your scope and work upward.
  • It is likely that if multiple users are concurrently using the app, it may not work. If so, please try again later.
